# Матилэнд: внедрение всего списка идей (кроме «Технического» и Умни)

Внедряю идеи 1–32 и 39–56 + 45–49 из согласованного списка. Идеи 33–38 (Умня) и 57–60 (Техническое) — исключены по вашей просьбе. Идеи «нужен бэкенд» делаю в локальных адаптациях без сервера: №15 дуэль на одном устройстве, №32 конструктор питомца, №45 родительская зона с локальным PIN, №48 лидерборд между профилями устройства.

## 1. Фундамент (библиотеки)
- `src/lib/tasks.ts` (новый): 12 типов задач — арифметика, пропущенное число, сравнение, выбор знака, доли (SVG-пицца), периметр/фигуры, часы (SVG-циферблат), деньги/сдача, текстовые задачи; `buildRound` с повтором ошибок; `hintFor` — подсказка по типу.
- `sound.ts` — Web Audio без файлов: верно/неверно/монета/сундук/фанфары/тик колеса + тумблер.
- `quests.ts` — пул квестов, 3 активных, прогресс и награды.
- `achievements.ts` — ~14 бейджей с наградами (монеты/самоцветы/редкие цвета).
- `economy.ts` — сундуки, колесо удачи (раз в день), ежедневный вход (календарь 7 дней), сделка дня −30% (детерминированно от даты), сезонный пропуск (30 уровней, сезонные предметы).

## 2. Стор v2 (`PlayerContext.tsx`, перезапись)
- Мультипрофили (`profiles[]` + `activeId`) с миграцией старого профиля; переключатель и создание героев.
- Новые поля: самоцветы, квесты, достижения, дневная серия, колесо/день, ежедневный вызов, сезон, статистика по темам, пул ошибок, комната, питомец (кличка + свой дизайн), друг-компаньон, редкие цвета, лимит времени/день, PIN родителя, тумблеры звук/тема.
- Центральное `finishGame` обновляет всё и выдаёт тосты-награды («Достижение!», «Квест выполнен», «Новый уровень», «Сундук!»).

## 3. Персонаж (`CharacterView.tsx`)
Эмоции (радость/грусть/вау) в игре; рост с уровнем (крылышки с 5-го, нимб с 8-го); новые слоты: крылья/плащ, предмет в лапку, узор на теле; редкие цвета (золотой, радужный); свой питомец из конструктора; друг-компаньон; режим «голова» для аватара в доке.

## 4. Комната героя
`RoomScene` + страница `/room`: обои, пол, постер, игрушка, лампа — товары в магазине.

## 5. Игра v2 (`Game.tsx`, `TaskView.tsx`)
Режимы: классика / «На время» (60 сек) / «Выживание» (3 жизни) / «Без ошибок»; адаптивная сложность; повтор ошибок в раунде; кнопка-подсказка; тряска при ошибке; звуки; эмоции персонажа; отчёт по типам задач («слабое место»); родительский лимит времени; ежедневный вызов раз в день.

## 6. Главная v2 — карта мира
Маршрут из островов-тем со звёздами мастерства + узлы мини-игр, олимпиады, дуэли, ежедневного вызова; клик → выбор сложности и режима. Виджеты: рекорд, квесты, сезон; модалки: ежедневный вход, колесо удачи, сундук.

## 7. Мини-игры, Олимпиада, Дуэль
- `/minigames`: «Ловим ответы» (падающие облачка), «Парочки» (пример↔ответ), «Лото» (карточка 3×3).
- `/olympiad`: 5 раундов с растущей сложностью и кубком.
- `/duel`: двое на одном устройстве по очереди, победа — монеты.

## 8. Магазин v2
Категории + «Комната», «Друзья», «Легендарные» (самоцветы), «Редкие цвета»; бейдж «Товар дня −30%»; метки сезонной коллекции.

## 9. Профиль v2
Звания (Новичок→Магистр), витрина достижений, тепловая карта за год, банк (обмен монет↔опыта), кличка питомца, перекраска (с редкими цветами), конструктор питомца, грамота (SVG → скачивание).

## 10. Родительская зона (`/parent`, вне дока)
Локальный PIN; сводка по детям (раунды, точность, слабые темы, время сегодня); лимит времени/день; лидерборд; перевод монет между профилями; управление профилями.

## 11. Оболочка
Тёмная тема «ночная Матилэнд» (переопределение токенов + тумблер, замена жёстких text-white); тумблер звука; сезонный декор (листья/снег/лепестки/блики по месяцу); аватар героя в доке; переключатель профилей в шапке; PWA (vite-plugin-pwa, офлайн); планшетные тач-улучшения.

## 12. Файлы
Новые: lib (tasks, sound, quests, achievements, economy), components (RoomScene, TaskView, тосты, сундук, колесо, ежедневка, квесты, сезон, теплокарта, грамота, переключатель профилей), pages (MiniGames, Olympiad, Duel, Room, Parent). Перезапись: PlayerContext, CharacterView, Game, Home, Shop, Profile, PageShell, App, index.css, dock, shopItems, vite.config. Мелкие правки: Assistant (адаптивный цвет), coin-badge (+GemBadge), flow-button (тема).

## 13. Проверка
`npm i -D vite-plugin-pwa`; зелёный `npm run build`; браузерный прогон: новый профиль → карта → режим «на время» → сундук → колесо → квест → покупка → комната → родительская зона (PIN) → тёмная тема. Отчёт по каждому шагу в финальной сводке.
